# CHINESE-SOURCE-INTELLIGENCE.md — LanDeng

Methodology for using Chinese-language sources to create original, differentiated English content. Chinese research is a **competitive moat**, not a translation pipeline.

## Pipeline

```
Chinese internet discovery
→ source classification (S1–S5)
→ multi-source collection
→ claim extraction
→ entity extraction
→ terminology extraction
→ cross-source analysis
→ conflict detection
→ evidence classification
→ knowledge gap identification
→ English content gap identification
→ original angle
→ independent English content
→ knowledge graph update
```

## Source types

- Chinese search engines (Baidu, Sogou, 360)
- Chinese academic sources (CNKI, Wanfang, 维普) — when accessible
- Chinese industry websites and manufacturer information
- Chinese forums and community discussions (知乎, 百度知道, 豆瓣, specialized forums)
- Chinese historical / cultural sources (古籍 digitizations, museum resources, 中医/本草 records)
- Chinese terminology and standards

## Rules

1. **Never direct-translate** Chinese pages. Output must be **analyzed + synthesized + original + differentiated**.
2. **Classify every source** (S1–S5). Commercial sources carry bias.
3. **Extract, don't copy.** Pull facts, entities, terminology, and claims — then write independently.
4. **Reconcile conflicts** between Chinese and English sources. Show disagreements.
5. **Identify the English content gap:** topics well-documented in Chinese but poorly/incorrectly documented in English are high-priority opportunities.
6. **Terminology discipline:** one Chinese word ≠ one English word. Maintain CHINESE-ENGLISH-GLOSSARY.md.
7. **No fabricated Chinese sources.** Every Chinese claim keeps provenance (source, type, date, URL, claim, evidence level).

## Output

Every research pass updates: RESEARCH-INVENTORY.md, CHINESE-ENGLISH-GLOSSARY.md, KNOWLEDGE-GRAPH.md, and produces an original content opportunity in SEO-MASTER-MAP.md.
