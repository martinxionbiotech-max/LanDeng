# ORGANIC-ENTRY-MAP.md — LanDeng

Maps each validated demand cluster to its full organic path: query → landing page → knowledge path → commercial path → conversion.

## Schema

```
Query → Search intent → Entity → Question → Best content format
→ Target page → Internal knowledge path → Commercial path → Conversion
```

## Intent types

What · Why · How · Which · Difference · Comparison · Best · Is · Safety · History · Culture · Ingredient · Material · Manufacturing · Supplier · Manufacturer · Wholesale · OEM · Private Label.

## Example path (Agarwood)

```
Query: "what is agarwood"
  → Intent: informational
  → Entity: Agarwood
  → Format: Encyclopedia
  → Landing: /ingredients/agarwood/
  → Knowledge path: agarwood → materials → burning → quality → comparison
  → Commercial path: agarwood product → wholesale → OEM
  → Conversion: Request a Quote / Sample
```

## Rules

- One entry per **validated** demand cluster (not per query variation).
- Every entry must terminate in a defined conversion (or explicitly have none).
- The path must be **natural** — no aggressive sales interruption in educational content.
