# 05 — 原创性证据审计（Originality Evidence）

## 一、可验证的原创分析框架

本站原创性并非"换个说法复述英文通用内容"，而是建立在**中文一手史料 + 植物分类学 + 采购/制造实务**三根支柱上：

1. **中文源情报框架**：逐页引用 香乘（明·周嘉胄，1641）、本草纲目、梦粱录（吴自牧）原文并给出白话释义。例：
   - /ingredients/agarwood/ 引用香乘四结："沈香入水即沉，其品凡四。曰熟结…曰生结…曰脱落…曰虫漏…"
   - /ingredients/paicao/ 逐字引用："排草出交址…草根也，白色，状如细柳根，人多伪杂之…"
   - /chinese-incense/（concept）引用梦粱录："烧香点茶，挂画插花，四般闲事，不宜累家"
   这类「古籍原文 + 释义 + 现代对照」在普通英文 SEO 站几乎不可见，是**难以替代的原创资产**。

2. **"传统 vs 证据"的诚实分层框架**：每页明确"传统使用=传统、科学证据=证据、贸易术语=贸易术语"，并显式拒绝疗效声明。这不是通用结论，是贯穿全站的**方法论原创**（见 /blog/landeng-editorial-methodology/ 声明）。

3. **采购/制造实务框架（B2B 独有）**：一致性地提出"粉的粒径/含水率取决于配方与产线，无可迁移的通用值"、"一致性胜过一次性顶级品"、"配方所有权是合同条款非默认"——这是**供应链独特知识**，非网络通用内容。

## 二、来源比较、矛盾与不确定性

- **来源比较**：植物分类锚定 GBIF + Flora of China；香料史锚定 Wikisource（香乘/本草纲目）+ ctext.org；空气质量锚定 PMC + ALA + EPA + CPSC。层级清晰。
- **明确标注的不确定性**（罕见的诚实）：
  - 奇楠五色等级高低**"来源间有争议"**，标注为市场术语。
  - "qínán" 词源**"uncertain"**，明示不确定。
  - 排草"古典为根 vs 现代为全草"的**身份差异**，明示为 provenance note。
- **无编造**：不编造实验数据、检测数据、作者经历、专家身份、引用（符合红线 4）。

## 三、逐篇抽样（最有价值原创信息 / 可被替代内容 / 缺失 / 最值得增加 3 项 / 需补来源类型）

### 抽样 1：/ingredients/agarwood/
- **最有价值原创**：沉香"木质状态非物种"+ 香乘四结原文 + 奇楠油包木结构 + 掺假筛查法。
- **可被替代**：通用"沉香昂贵"表述（多数站也有）。
- **缺失**：无具体产区价格梯度表（可接受）。
- **最值得增 3 项**：① 奇楠五色等级的可视化对比表 ② 种植沉香人工结香年限的权威数据 ③ 真伪显微/GC-MS 检测的分级说明。
- **需补来源**：CITES 附录具体条目链接（已有）、行业检测机构方法。

### 抽样 2：/ingredients/calamus/
- **最有价值原创**：β-asarone 的 FDA/EC 限制 + 二倍体/四倍体差异 + 摄入 vs 燃烧的区分。
- **可被替代**：通用"菖蒲是香料"。
- **缺失**：具体 β-asarone 限量数值（可补）。
- **最值得增 3 项**：① FDA 21 CFR 具体条款号 ② EC 法规号 ③ 燃烧产物是否含 β-asarone 的文献说明。
- **需补来源**：官方法规原文（FDA/EC）而非二手。

### 抽样 3：/blog/incense-smoke-air-quality-evidence/
- **最有价值原创**："自然≠无烟"的纠偏框架 + 45mg/g vs 10mg/g 的诚实引用 + 缓解表（通风/电热/HEPA）。
- **可被替代**：无（这类诚实框架正是空白）。
- **缺失**：无精确到具体房间体积的暴露模型（可接受）。
- **最值得增 3 项**：① 燃烧时长×通风率的定量暴露示例 ② 各格式（线香/盘香/塔香/隔火）PM 差异实测 ③ 儿童/孕妇敏感人群的专门段落。
- **需补来源**：原始 PMC 全文链接（已有 PMC ID，可补 DOI 直链）。

### 抽样 4：/blog/oem-vs-private-label/
- **最有价值原创**："谁开发产品"单问决策 + 配方所有权是合同条款 + 无价目表/MOQ 按项目报价的诚实声明。
- **可被替代**：通用 OEM/PL 定义。
- **缺失**：无具体报价（有意为之，符合诚信）。
- **最值得增 3 项**：① 真实流程耗时区间（明示"on request"）② 常见合同陷阱清单 ③ 打样迭代的典型轮次说明。
- **需补来源**：WIPO/USPTO 已列，可补 IFRA 标准。

### 抽样 5：/blog/how-aromatherapy-works/
- **最有价值原创**："关联真实、药理学多未证实"的二分 + 嗅觉→边缘系统机制 + "气味是仪式锚点非剂量"。
- **可被替代**：通用"薰衣草放松"。
- **缺失**：无具体神经影像文献（可补）。
- **最值得增 3 项**：① 嗅觉通路具体脑区文献 ② 期望效应/安慰剂的说明 ③ 气味记忆的心理学研究。
- **需补来源**：神经科学原始文献（目前仅"established literature"笼统标注）。

## 四、是否为"为关键词而建的页面"？

对 115 blog 页标题+主关键词抽查：每页主关键词均对应**真实可回答的搜索意图**（"how to burn incense safely"→操作；"oem vs private label"→决策；"is incense bad for you PM2.5"→证据）。未发现"拼凑关键词、无对应内容"的凑数页。

**空泛开场/机械总结检测**：开场多为**直答/技术答案/数据摘要**（answer-first），非"在当今快节奏社会…"式空泛；结尾 Summary 为实质归纳，非机械"总之"复读。

## 五、结论

- 原创性：**高**。核心资产（中文古籍源情报 + 分类学 + 采购实务）是普通搜索难以获取的独特信息。
- 可被替代内容占比：低（仅少量通用定义段）。
- 主要提升空间：**补权威一手来源直链**（法规条款号、DOI、神经影像文献），进一步把"已标注为笼统"的来源坐实。
- 无证据显示任何页面是"为凑关键词而造"。
