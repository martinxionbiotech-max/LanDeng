# RESEARCH-MODEL.md — LanDeng

Schema for the research ledger. One record per research thread. The actual records live in RESEARCH-INVENTORY.md.

## Fields

| Field | Meaning |
|---|---|
| Research ID | stable ID (R-###) |
| Topic | research question / subject |
| Chinese keywords | Chinese search terms |
| English keywords | English search terms |
| Entities | entities involved |
| Sources | source list (see source matrix) |
| Source quality | S1–S5 mix |
| Claims | extracted claims |
| Evidence level | Traditional / Historical / Preliminary / Established / None |
| Conflicts | disagreements between sources |
| Consensus | what sources agree on |
| Uncertainty | open questions |
| Knowledge gap | what's missing |
| English content gap | what English lacks |
| Original angle | our differentiated contribution |
| Target page | planned output asset |
| Status | proposed / researching / drafted / published |
| Last reviewed | date |

## Rules

- **Provenance is mandatory** for every important claim.
- **Conflicts are shown**, never silently resolved.
- **No fabricated sources**, no fake academic citations.
- We are not an academic institution — label "research" honestly as **editorial / descriptive research**, not clinical research.
