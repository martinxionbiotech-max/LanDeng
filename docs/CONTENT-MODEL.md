# CONTENT-MODEL.md — LanDeng

Content types and their required structure. Every type enforces a minimum information density; thin pages are not permitted.

## Content types

1. **Encyclopedia** (entity page) — ingredients, materials, terminology
2. **Guide** — how-to, practice, safety
3. **Research** — methodology + findings with provenance
4. **Comparison** — entity vs entity, format vs format
5. **Glossary** — terminology ledger
6. **Timeline** — historical sequence
7. **FAQ** — question clusters
8. **Journal** — editorial
9. **Product** — knowledge-rich product page
10. **Wholesale** — commercial
11. **OEM** — commercial

## Encyclopedia (ingredient/material) structure

```
Entity header (name, Chinese term, pinyin, scientific name, type)
Direct answer
Aroma profile
Botanical source / origin / geography
Materials + processing
Traditional context + historical context
Incense use + burning characteristics
Quality factors + adulteration notes
Safety + evidence level
Comparison (vs related entities)
FAQ
Related entities / research / products
Commercial bridge (contextual, not aggressive)
```

## Research page structure

```
Research question
Methodology
Source matrix (S1–S5 classification)
Claims + evidence classification
Conflicts + uncertainty
Findings
Original contribution
Limitations
Related entities / further reading
```

> **Research ≠ clinical research.** We are not an academic institution; we label evidence levels honestly (Traditional / Historical / Preliminary / Established / No Established Evidence) and never upgrade a traditional belief into scientific fact.

## Product page structure

```
Product summary → Aroma profile → Ingredients → Materials → Formula (where applicable)
→ Manufacturing → Burn characteristics → Traditional context → Suggested use → Safety
→ Related knowledge → Related ingredients → Related materials → Related products
→ Wholesale → OEM
```

## AIO overlay

All major content types follow the AI answer pattern (direct answer → definition → key facts → detail → comparison → evidence → analysis → examples → related). See AIO-STRATEGY.md.

## Governance

Every content asset must satisfy: search intent · entity · user problem · information gain · evidence · original value · internal links · commercial relevance · AIO potential. See CONTENT-GOVERNANCE.md and the Content Quality Gate.
